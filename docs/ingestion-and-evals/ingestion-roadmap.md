# Ingestion improvements roadmap

The next change is to unify collection routing and cleanup. Repeated submissions, retries, competing workers and failed reprocesses are now safe. Before this code runs against the production database, apply the new migration (`alembic upgrade head`), which adds `documents.processing_token`.

## Completed

- Reprocessing reports stage failures and preserves source metadata when it reuses markdown or chunks. Explicit titles take precedence over parser titles. [Orchestrator](../../ingestion/orchestrator.py) · [Collection service](../../services/collection_service.py)
- The CLI processes all supplied sources when given a shared title. Failed and incomplete batch items, including work lost when a bulk worker exits, produce a nonzero exit code. [Single and multi-source CLI](../../scripts/ingest.py) · [SuttaCentral batch CLI](../../scripts/ingest_batch.py) · [Bulk CLI](../../scripts/ingest_all.py)
- Ingestion computes vectors in memory and commits the vectors, chunks, table of contents, and completed status in one transaction. The disposable Postgres regression test interrupts both embedding and persistence, then verifies the successful retry has exactly one vector per chunk. The targeted run passed 128 tests. [Vector adapter](../../ingestion/embed.py) · [Persistence stage](../../ingestion/stages.py) · [Regression test](../../tests/ingestion/test_atomic_publication.py)
- The whole pipeline runs end to end in tests on SQLite, with only the source and the vector store faked, covering a new source, a failure, a retry and each reprocess mode. [End-to-end tests](../../tests/ingestion/test_orchestrator_e2e.py)
- Stages raise and the pipeline records failures in one place; unexpected errors now name their exception type. `process()` is split into preparing a document, running the pipeline, and a status recorder, and returns a typed result. [Orchestrator](../../ingestion/orchestrator.py) · [Status recorder](../../ingestion/status.py)
- Ingestion reads its embedding model, batch size and default collection from the same settings as retrieval, so stored vectors and query vectors cannot use different models. Importing a SuttaCentral parser no longer loads torch (0.2 s instead of about 3.6 s). [Vector adapter](../../ingestion/embed.py) · [Interfaces](../../core/interfaces.py)
- A submitted source goes through one admission rule. Sources are compared in canonical form, so a SuttaCentral ref and its reading URL are one document. A completed document returns its existing result without running, and one that never completed resumes, reusing its stored markdown. Each run claims its document, so a second run gets `DocumentBusyError`; a claim lapses after `INGESTION_LEASE_SECONDS` without a status write, and a run that lost its claim cannot publish. Reprocessing replaces the old chunk rows and vectors inside the publish transaction, so a failed reprocess keeps the previous version published; it also removes vectors older runs left without chunk rows. `from_embedding` keeps the chunks' UUIDs. Checked on disposable Postgres, including a real SuttaCentral and Voyage run. [Admission](../../ingestion/admission.py) · [Orchestrator](../../ingestion/orchestrator.py) · [Persistence stage](../../ingestion/stages.py) · [Migration](../../alembic/versions/c4f2a8d61b93_documents_processing_token.py) · [Tests](../../tests/ingestion/test_retry_and_ownership.py)

## Next in order

1. **Unify collection routing and cleanup.** Use one configured collection default and retain the original collection for retries and deletion. Define how to resolve older rows before changing the default; production holds 4,050 documents, all canonical `sc:` references and all completed, with no PDF or URL documents (checked 2026-11-22). Route failed-document deletion through the shared cleanup operation. Use the existing database verifier to look for vectors or chunks left unmatched by earlier versions, and review any proposed repairs before applying them. [Ingestion service](../../services/ingestion_service.py) · [Queue view](../../views/queue.py) · [Database verifier](../../scripts/verify_database.py)
2. **Add ingestion to the existing FastAPI app.** Share typed submission and retry operations with the CLI and Streamlit. Start with validated SuttaCentral references, return `202 Accepted`, and let callers poll a status resource. Use a persisted job record with recovery for unattended runs. Extend to PDFs after introducing managed uploads with content checksums. Add arbitrary URL ingestion only after defining allowed destinations, redirects, and response size limits. [Corpus workbench](../learning/arcs/2026-11-17-corpus-workbench.md) · [API and jobs plan](README.md)

## Independent improvements

- **Enforce the chunk size limit.** Keep semantic boundaries when they fit. Split any remaining oversized spans deterministically and count separators when merging. Changing boundaries can invalidate chunk IDs and evaluation labels, so measure retrieval impact on a separate corpus snapshot. [Chunker](../../ingestion/chunking.py)
- **Preserve heading levels and hierarchy.** Store structured heading paths so repeated heading names and separator characters do not distort the table of contents. Keep a reader for existing metadata. [Chunker](../../ingestion/chunking.py) · [Table of contents builder](../../ingestion/stages.py)
- **Bound the work running outside HTTP requests.** Parsing, model inference, embedding, and database access include blocking calls. Use a bounded worker and measure stage timings and database round trips before changing concurrency or progress reporting. [Pipeline stages](../../ingestion/stages.py) · [Corpus workbench](../learning/arcs/2026-11-17-corpus-workbench.md)
- **Improve parser and adapter coverage.** Replace the suite-wide PDF dependency mocks with scoped fakes and a real import check. Honor the OCR setting. Remove or correct the unused vector metadata deletion method, which currently reports success even though the legacy adapter ignores its filter. [Parser](../../ingestion/parsing.py) · [Test configuration](../../tests/conftest.py) · [Vector adapter](../../ingestion/embed.py)
